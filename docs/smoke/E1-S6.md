# Smoke test: string catalog (OPA-12)

Proves the plugin's strings follow the Omarchy language and change when it changes.

## Prerequisites

1. Get this branch into the installed plugin.
   - If the plugin is already installed as a clean git checkout at `~/.config/omarchy/plugins/elvisgastelum.omapass`, run `make dev` from a checkout of the branch under test. It runs `make check`, copies the working tree over the installed plugin and restarts the shell. It refuses a dirty or non-git install unless you run `make dev FORCE=1`.
   - If the plugin is not installed, run `omarchy plugin add "$PWD" --enable` from the checkout, then `omarchy restart shell`.
2. Note the current language: `omarchy-language` with no argument prints the current code. English is `en`. If `~/.config/omarchy/language` does not exist, the shell uses English.

## language

1. In English, open the overlay (click the bar key icon or run `omarchy-shell omapass toggle`). Expected: the card reads "service ok". Press Esc. Expected: the overlay closes.
2. Switch to Spanish: Omarchy menu Setup > Language > Español, or `omarchy-language es`. It may ask for a password to generate the locale, then it writes the language file and restarts the shell. Expected: the shell comes back with its own UI in Spanish.
3. Open the overlay again. Expected: the card reads "servicio activo". Press Esc. Expected: the overlay closes.
4. Live switch without a restart (the catalog watches the language file). The overlay closes when you click outside it, so schedule the change first: in a terminal run `(sleep 8; echo en > ~/.config/omarchy/language) &`, then open the overlay within 8 seconds with the bar icon and leave it open. Expected: after a few seconds the card changes from "servicio activo" to "service ok" while the overlay stays open, without a shell restart. Close it, run `(sleep 8; echo es > ~/.config/omarchy/language) &` and repeat. Expected: the card changes back to "servicio activo". This edits only the language file the shell itself reads; step 5 restores the full setting.
5. Switch back: Setup > Language > English, or `omarchy-language en` (or the code noted in the prerequisites). Expected: the shell restarts in English and the card reads "service ok".
6. Check the logs: `journalctl --user -b -t omarchy-shell --since "-10 min" | grep -i -E "omapass|i18n|qml|warn|error"`. Expected: no QML errors or warnings that name this plugin's files, and the card never shows a raw key such as "skeleton.serviceOk".

## Restore afterwards

If the plugin was installed only for this test, go back to main. From a checkout of `main`, run `make dev` again, or run `make uninstall` then `make install`.
